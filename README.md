#  BEU Result Scraper & Analytics

A powerful automation tool designed to bridge the gap between official university portals and institutional data analysis. This tool allows users to fetch bulk results from the Bihar Engineering University (BEU) portal and process them into structured reports.

##  Key Features
- **Automated Data Scraping:** Uses Selenium to fetch batch-wise results directly from the BEU portal.
- **Advanced Analytics:** Sort results by CGPA, registration numbers, or semester performance.
- **Smart Filtering:** Easily isolate "Back Paper" students or "Top Performers" with one click.
- **Multi-Format Export:** Supports CSV downloads and professional Multi-Sheet Excel (XLSX) reports.
- **Interactive UI:** Built with Streamlit for a smooth, web-based experience.

##  Tech Stack
- **Web Scraping:** Selenium
- **Data Processing:** Pandas, OpenPyXL
- **Frontend/GUI:** Streamlit
- **Language:** Python 3.x
